# Портфолио — Aleksandr P.

Персональное портфолио на React с интерактивной 3D-сценой, анимациями при прокрутке, горизонтальной галереей проектов и переключением между русским и английским языками.

**Стек:** React 19 · Vite · GSAP (ScrollTrigger, SplitText) · Three.js · React Three Fiber · Lenis · CSS.

## Запуск проекта

Установите зависимости:

```bash
npm install
```

Запустите сервер разработки:

```bash
npm run dev
```

Сайт будет доступен по адресу [http://localhost:5173].


## Структура проекта

| Путь | Описание |
|---|---|
| `src/assets/` | Изображения и статические ресурсы. |
| `src/components/` | Компоненты и секции сайта: навигация, проекты, опыт работы, контакты и другие элементы. |
| `src/content/en.js` | Тексты интерфейса на английском языке. |
| `src/content/ru.js` | Тексты интерфейса на русском языке. |
| `src/content/LanguageContext.jsx` | Контекст для управления языком интерфейса. |
| `src/hooks/useScrollReveal.js` | Переиспользуемые анимации появления элементов при прокрутке. |
| `src/styles/tokens.css` | Дизайн-токены: цвета, типографика и отступы. |
| `src/three/Background3D.jsx` | Компонент фоновой 3D-сцены. |
| `src/three/Scene.jsx` | Компонент 3D-сцены. |
| `src/three/stage.js` | Общее состояние 3D-сцены. |
| `src/three/useStageScroll.js` | Синхронизация 3D-анимации с прокруткой страницы. |
| `src/config.js` | Контактные данные и ссылки: электронная почта, Telegram, GitHub, hh.ru и резюме. |
| `src/smoothScroll.js` | Настройка плавной прокрутки страницы. |
| `src/App.jsx` | Корневой компонент приложения. |
| `src/main.jsx` | Точка входа приложения. |
| `src/index.css` | Глобальные стили. |
| `src/intro.js` | Логика вступительной анимации. |

## Особенности

- Интерактивная 3D-сцена с анимацией, связанной с прокруткой страницы.
- Горизонтальная галерея проектов.
- Временная шкала профессионального опыта.
- Переключение языка интерфейса между русским и английским.
- Анимации на GSAP.
- Плавная прокрутка с Lenis.
